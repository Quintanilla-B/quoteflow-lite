## QuoteFlow Lite

QuoteFlow Lite helps tour operators, agencies and independent professionals create bilingual estimates and keep the next commercial action visible without adding another subscription.

- Editable bilingual service catalog
- Spanish and English quote sheets
- Subtotal, discount, tax, deposit and balance calculations
- Lightweight opportunity CRM and summary
- Transparent formulas, no VBA or macros
- Independent Excel file with quick-start guides in ES/EN

## Technical service scope

The USD 109 audit covers one public web application, API or open-source repository and up to two hours of investigation. The handoff contains:

1. Minimal reproduction and expected versus actual behavior.
2. A concise technical diagnosis.
3. One focused patch ready for pull-request review.
4. Tests or other validation evidence.
5. Written handoff and one revision.

Security bypasses, credential handling, destructive testing and unrelated feature work are excluded.
